The Workflow

From zero to production in minutes

1

Platform Request

Sign in with GitHub and request your team's isolated environment. Our automated engine sets up your namespaces and RBAC.

$ curl -X POST https://mctl.me/request
↓
2

Create Service

Use pre-configured templates in Backstage. MCTL handles the scaffolding and Git repository creation.

$ open https://backstage-preview.mctl.me
↓
3

Auto Deployment

ArgoCD monitors repository. On every push, it builds, tests, and deploys your service to production.

ArgoCD sync → Deployed 🚀
