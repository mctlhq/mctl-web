Auth & Security

            
How access works

            

                

                    
🔑

                    
Token validated per request

                    
Your GitHub token is checked against the GitHub API on every MCP call. It's never stored by the server.

                

                

                    
👥

                    
Team-scoped access

                    
Access is limited to tenants you belong to, resolved from org membership in the GitOps repo. Admins can operate on all tenants.

                

                

                    
📝

                    
Full audit trail

                    
Every write operation is an Argo Workflow, which produces a git commit. Who did what, when, and why — all in version control.

                

            

        

    


    
    

        

            
FAQ

            
Common questions

            

                

                    
What can the AI do?

                    
Read platform state (services, tenants, resource usage, workflow logs) and trigger pre-defined operations: deploy services, create workspaces, provision databases. The AI calls these tools based on your natural-language requests.

                

                

                    
What can it NOT do?

                    
Delete tenants or services — those operations aren't exposed. No direct kubectl, no Vault secret reads, no raw cluster access. The AI operates through a controlled set of tools with a defined scope.

                

                

                    
Where do write operations actually go?

                    
Write operations submit Argo Workflows. Each workflow produces a git commit to the GitOps repo. ArgoCD picks up the commit and syncs the cluster. Full traceable chain from "AI was asked" to "pods running".

                

                

                    
Do I need to install anything?

                    
No binary required. The server runs at https://api.mctl.ai/mcp. Add the config to your AI client, restart it, and you're connected.

                

                

                    
What GitHub token scope is needed?

                    
The OAuth flow on this page requests read:org, read:user, and user:email. This lets the server verify your GitHub org membership and resolve your team access. If you use gh auth token directly, it works too — the CLI already grants the needed scopes.
